# 🐔⚙️ Cluckwork Valley

> **Farms that farm themselves. Chickens that run the company.**

The promotional website for **Cluckwork Valley**, an automated factory & smart farm built in Minecraft Education by **Cluckwork Studios** (Year 9 Computing Technology, Task #4: *Creating games and simulations*).

🌐 **Live site:** https://4bzdog.github.io/cluckwork-valley/

## What's inside

| File | What it is |
|---|---|
| `index.html` | The single landing + content page: story, map, videos, gallery, player guide, tech showcase, ethics, portfolio, studio and press kit |
| `styles.css` | The brand: pixel headings, chunky borders, light/dark "day/night cycle" |
| `app.js` | Tabs, lightbox, the CEO chicken clicker, and the code that turns `media.js` into cards |
| `media.js` | ⭐ **The only file students edit** to add selfies, screenshots and videos |
| `assets/` | `shots/` screenshots · `team/` selfies · `bts/` behind-the-scenes · `video/` mp4s |
| `docs/HOW-TO-ADD-MEDIA.md` | Step-by-step guide for adding media, with privacy rules and a video shot list |
| `docs/PORTFOLIO.md` | The Studio Planning Portfolio in text form (requirements, IPO, flowchart, sprints, bugs, AI log) |
| `docs/PROMO-KIT.md` | Taglines, blurbs, trailer script, social posts |
| `docs/TASK-MAPPING.md` | How each part of the site meets the Task #4 marking criteria |

## Run it locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Every push to `main` runs `.github/workflows/pages.yml`, which publishes the site to GitHub Pages. Deploys take about 1 minute.
